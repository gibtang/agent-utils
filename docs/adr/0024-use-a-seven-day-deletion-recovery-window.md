# Use a seven-day deletion recovery window

Deleted Inboxes stop accepting Events immediately, and deleted State and Files become inaccessible immediately. Resource deletion can be reversed from Trash for seven days. Account deletion also has a seven-day cancellation period. After the recovery period, data is permanently removed from active systems; encrypted backups expire through the normal backup cycle within 30 days. Minimal billing records are retained only where legally required.
