# Require an end-to-end Agent Owner journey before launch

Launch requires a semi-technical Agent Owner to sign in with Google, pair Codex or Hermes without manually handling an API key, have the Agent create and connect an Inbox, receive and process a test Event, use State, complete the File lifecycle, upgrade through Stripe, and understand and recover from failures in the dashboard. Automated coverage must include permissions, Event claims, source verification, billing limits, retention and deletion.
