# Use plan-based retention

Event history is retained for 7 days on Free, 30 days on Plus and 90 days on Pro; maximum File lifetime is 24 hours, 7 days and 30 days respectively. State persists until explicitly deleted or expired and counts against plan storage. Upgrades extend resources that have not expired, while downgrades use a grace period instead of immediately deleting data.
