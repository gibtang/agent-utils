# Notify Agent Owners only when action is needed

The dashboard contains the complete activity history. At launch, email is reserved for Connections that need attention, Events that repeatedly fail or remain unprocessed, usage reaching 80 or 100 percent of a limit, billing changes, and security-sensitive owner actions. AgentUtils does not email for every Event and does not describe owner email as a way to wake an Agent. Per-Inbox notification preferences are deferred.
